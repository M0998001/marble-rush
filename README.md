# Marble Rush 3D 🟡🔵🔴

A playable 3D arcade marble-racing prototype for iPhone, iPad, and desktop browsers. Everyone joins on **one device** and watches the marbles race through a randomly generated obstacle course.

## ▶️ Play

**[Launch Marble Rush 3D](https://m0998001.github.io/marble-rush/)**

If this link is not live yet, the repository owner should open **Settings → Pages**, choose **Deploy from a branch**, set **main** and **/(root)**, and click **Save**. GitHub Pages usually publishes shortly after enabling it.

## How it works

1. Select **Start Racing**.
2. Choose **Free for All** or **Team Battle** and pick 2–16 players.
3. Name the competitors and select their marbles.
4. Preview or regenerate a course and launch the race.
5. Watch the results, earn coins, and unlock courses or cosmetics.

### Features

- Dependency-free browser game with 3D WebGL graphics
- Two local shared-screen game modes: Free for All and Teams
- 2–16 competing marbles
- Four course themes, randomized obstacle layouts, and race lengths
- Mobile- and tablet-friendly controls, standings, and camera tracking
- Coins, cosmetic unlocks, and progress saved **locally in this browser on this device**

## Running locally

Open **[index.html](index.html)** in a current desktop browser. No build, account, installation, or external dependencies are required. For mobile browsers, use the published HTTPS link.

## About this prototype

This is an early, playable prototype. It uses an original lightweight WebGL renderer and JavaScript physics, not Unity; its 3D courses and physics need additional real-device testing and production polish. Sharing the link allows others to play their own local sessions, but does not join separate devices into one online multiplayer race.
